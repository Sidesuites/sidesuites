Update the rules

When a city adopts or amends an ADU ordinance: edit its rows in the spreadsheet (Municipality table for the verdict and narrative, Scoring rules for districts, lot minimums and caps), then import it here. The map, colors and address checker switch to the new rules right away (saved in this browser).

Review status

Rows past their review date (120 days since "Last verified") are flagged. The weekly ADU ordinance watch job in GitHub also checks city council agendas and code sources and opens an issue when something changes.
